SIX WAYS TO WORK BETTER

필요한 순간에.
알맞은 스킬 하나.

첨부된 AI SKILLS V1.1 가이드의 여섯 가지 주제를 정리했습니다. 스킬은 AI의 작업 지침이며, 실행 환경에 따라 별도 프로그램이나 연결이 필요할 수 있습니다.

〈 / 〉
01 · CODE WITH INTENT

Karpathy Guidelines

먼저 생각하고, 단순하게 만들고, 필요한 부분만 수정하고, 결과를 검증하도록 돕는 코딩 지침입니다.

“이 버튼만 고치고 기존 기능은 유지해 줘.”
Karpathy의 관찰에 영감을 받은 제3자 지침입니다.

▷
02 · UNDERSTAND VIDEO

Claude Video / Watch

영상의 장면과 자막·전사를 바탕으로 내용을 분석하도록 돕습니다. 지원되는 실행 환경과 추가 도구가 필요할 수 있습니다.

“핵심 장면과 해당 시간을 정리해 줘.”
채팅에 첨부하는 것만으로 실행되지는 않습니다.

Aa
03 · WRITE NATURALLY

Humanizer

반복되는 표현과 번역투를 살펴 한국어 문장을 읽기 편하게 다듬습니다. 교정·문체 지침과 함께 활용할 수 있습니다.

“의미는 유지하고 회사 소개문을 자연스럽게 다듬어 줘.”
원본 수치와 사실은 별도로 확인하세요.

◎
04 · KEEP THE CONTEXT

Agent Memory

프로젝트의 결정과 작업 이력을 외부에 저장하고 다시 불러오는 기억 시스템입니다. 서버·MCP 연결이 필요한 별도 구성입니다.

“지난번 결정과 수정 이유를 다시 찾아 줘.”
ChatGPT의 내장 메모리와는 다릅니다.

⌘
05 · BUILD STEP BY STEP

Superpowers

요구사항 파악부터 설계, 계획, 테스트, 검토까지 개발 흐름을 정리합니다. 작업 규모에 맞게 적용하는 것이 좋습니다.

“수정 범위를 정하고 검증한 뒤 결과를 보여 줘.”
작은 수정에는 절차를 간단히 적용하세요.

✦
06 · CREATE YOUR OWN

Skill Creator

반복 업무를 SKILL.md와 예시로 정리해 맞춤 스킬을 만드는 가이드입니다. 사용할 AI 환경에 맞게 준비합니다.

“우리 홈페이지 수정 원칙을 스킬로 만들어 줘.”
설치 지원 여부는 각 환경에서 확인하세요.

START SMALL. BUILD YOUR ROUTINE.

01 / SELECT

목적에 맞게 고르기

코딩, 문장 교정, 영상 분석 중 필요한 작업을 고르세요. 통합 ZIP에는 원본 저장소와 플랫폼별 파일이 함께 들어 있습니다.

02 / PREPARE

설치 형태 확인하기

압축을 풀고 README와 SKILL.md를 확인하세요. 전체 자료 묶음 ZIP을 그대로 스킬 설치창에 올리는 방식은 아닙니다.

03 / CHECK

작은 작업으로 확인하기

사용할 서비스의 지원 방식을 확인한 뒤 필요한 스킬을 등록하세요. 작은 예시 작업으로 실제 지침이 적용되는지 확인합니다.

첨부 자료를 기준으로 구성한 설명입니다. 원본 스킬과 ARTHUS에서 별도로 수정한 스킬은 구분해서 사용하세요. 다운로드나 파일 첨부는 설치 완료를 뜻하지 않습니다.
